# Plataforma web de gestión de reservas y flota de renting

Proyecto Intermodular · 2.º DAW Semipresencial · IES Severo Ochoa · Curso 2026-2027
Autora: Iris Rodríguez Ujj

## Descripción
Aplicación web para gestionar la contratación y la flota de vehículos de renting
a medio y largo plazo (12 a 48 meses). Conecta a los clientes con el equipo de
gestión de la empresa en tiempo real.

## Problema que resuelve
Las empresas medianas de renting suelen gestionar las reservas por teléfono,
correo o formularios desconectados del stock. Esto provoca solapamientos de
reservas (overbooking), esperas de más de 24 horas y falta de transparencia en
el precio.

## Funcionalidades previstas
- Registro, inicio de sesión y control de acceso por roles (Cliente, Gestor de
  Flotas y Administrador)
- Catálogo de vehículos con filtros por fechas, categoría, motorización y precio
- Simulador dinámico de cuotas según plazo y kilometraje anual
- Gestión de reservas con prevención automática de solapamientos
- CRUD de la flota y gestión de estados del vehículo
- Validación estricta de datos en formularios

## Tecnologías
HTML5, CSS3 y JavaScript (frontend) · PHP con Laravel (backend y API REST) ·
MySQL/MariaDB (base de datos)
